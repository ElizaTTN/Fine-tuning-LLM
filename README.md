# Структура проекта
- **`Diploma/`** — основная директория дипломной работы
  - **`datasets/`** — коллекция датасетов для анализа
    - **`science/`** — научный стиль текстов
    - **`literature/`** — художественный стиль текстов
    - **`journalism/`** — публицистический стиль текстов
  - **`src/`** — исходный код для дообучения модели
- **Course_work** — материалы для курсвой работы
# Описание датасетов
1. #### Научный стиль (datasets/science/)
Тексты в научном стиле
Исходный датасет: danasone/wikipedia_ru

2. #### Художественный стиль (datasets/literature/)
Художественные тексты (проза, рассказы)
Исходные данные:
inkoziev/ru_stories — корпус данных, где каждый объект состоит из 5 предложений
Kaggle Russian Literature — коллекция классической русской литературы
My data — самостоятельно собранные тексты

3. #### Публицистический стиль (datasets/journalism/)
Новостные и публицистические тексты
Исходный датасет: RicardoQi/lenta_ru_news
