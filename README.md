# Структура проекта
- **`Diploma/`** — основная директория дипломной работы
  - **`datasets/`** — коллекция датасетов для анализа
    - **`science/`** — научный стиль текстов
    - **`literature/`** — художественный стиль текстов
    - **`journalism/`** — публицистический стиль текстов
  - **`src/`** — исходный код для дообучения модели
- **Course_work** — материалы для курсвой работы
# Описание датасетов
1. #### Научный стиль (datasets/science/)<br>
Тексты в научном стиле<br>
Исходный датасет: danasone/wikipedia_ru<br>

2. #### Художественный стиль (datasets/literature/)<br>
Художественные тексты (проза, рассказы)<br>
Исходные данные:<br>
inkoziev/ru_stories — корпус данных, где каждый объект состоит из 5 предложений<br>
Kaggle Russian Literature — коллекция классической русской литературы<br>
My data — самостоятельно собранные тексты<br>

3. #### Публицистический стиль (datasets/journalism/)<br>
Новостные и публицистические тексты<br>
Исходный датасет: RicardoQi/lenta_ru_news<br>
